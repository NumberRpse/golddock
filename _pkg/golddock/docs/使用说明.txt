GoldDock · 黄金积存金桌面卡片  v1.1
=====================================

【这是什么】
一个始终置顶在桌面最上层的迷你卡片，实时显示「工银积存金」和「浙商积存金」的价格与当日涨跌幅。
单个 exe，免安装、免依赖（Win10 自带 .NET Framework 4.x），绿色可用。

【怎么用】
1. 双击 GoldDock.exe 即出现卡片，默认停在屏幕右上角。
2. 鼠标左键按住卡片任意位置就能拖动；位置自动记住，下次启动原位出现。
   卡片有没有被别的窗口挡住、有没有拿到焦点，都能拖。
3. 按 ESC 立即退出（鼠标在卡片上、或卡片是当前活动窗口时生效）。
4. 双击卡片 = 切换「紧凑模式 / 完整模式」。
5. 右键卡片弹出菜单：
     窗口置顶        —— 取消勾选后卡片会被其它窗口遮挡（默认开启）
     紧凑模式        —— 只留名称、价格、涨跌幅，高度减半
     刷新间隔        —— 3 / 5 / 10 / 15 / 30 / 60 秒可选（默认 5 秒）
     跌幅提醒...     —— 当日跌幅超过 N% 时闪一下边框并弹托盘气泡（默认 1%，填 0 关闭）
     浙商点差...     —— 浙商价 = 上金所 Au99.99 + 点差；填 0 = 自动跟随工行点差
     外观与颜色...   —— 预设（深色 / 浅色 / 金色 / 全透明）、四个颜色、背景不透明度
     背景全透明      —— 一键把背景不透明度设为 0（只留数字浮在桌面上，整块区域仍可拖动）
     开机自动启动    —— 写入当前用户启动项（可随时取消）
     立即刷新
     以当前价重置今日基准
     改用当日开盘价基准
     退出（或按 ESC）
6. 托盘区有图标：左键 = 显示/隐藏卡片，右键 = 同一套菜单。

【颜色约定】
红 = 涨，绿 = 跌，灰 = 平（A 股 / 国内习惯）。这四种颜色都能自己改。

【外观说明】
· 「外观与颜色...」里可以改背景色、文字色、上涨色、下跌色，以及背景不透明度（0~100%）。
· 不透明度 0% = 完全透明：卡片底色消失，只留价格数字浮在桌面上。
  此时程序会自动给文字加一圈深色描边，浅色壁纸和深色壁纸上都看得清。
  透明状态下整块矩形区域依然可以被鼠标点中、拖动（这是它和“色键透明”最大的区别）。
· 设置对话框自己也是置顶的，不会被卡片挡住，可以正常输入。
· 预设：深色（默认）/ 浅色 / 金色 / 全透明。

【数据来源与可信度】
· 工银积存金：中国工商银行网银公开行情接口，官方实时报价，角标显示「实时」。
· 浙商积存金：浙商银行没有公开报价接口，按「上金所 Au99.99 + 点差」推算，角标显示「推算」。
  点差默认「自动」——用「工行报价 − 上金所报价」的实时中位数估出来，比手工填常数更贴近；
  如果你知道浙商的实际点差，右键「浙商点差...」填进去即可（填 0 恢复自动）。
  因为点差在一日内近似固定，所以推算法的 **涨跌幅** 与真实值几乎一致，这正是本卡片要看的数字。
· 上金所 Au99.99：新浪财经行情（主源），东方财富（备用源）。

【“今天跌了多少”是怎么算的 —— 已改为当日开盘价】
  跌幅 = (现价 − 当日开盘价) ÷ 当日开盘价
· 当日开盘价取「上金所 Au99.99 今天日盘 09:01 的第一笔成交价」，目前实测是 786.00。
  数据来自东方财富的 1 分钟 K 线接口，程序每天开盘后取一次并缓存。
  注意：上金所行情里的“今开 803.90”是**前一晚夜盘**的开盘价，不是今天的开盘，不能直接用。
· 工银、浙商两行都不含夜盘，所以基准统一用日盘开盘价加各自点差。
· 工行官方给的当日最高/最低是它自己的报价区间，如果算出来的开盘价高于它自己的当日最高价，
  就以它的当日最高价为准（开盘不可能比当天最高还高），卡片不会出现超出当日高低区间的百分比。
· 卡片底部显示「开盘 786.00」，表示当前跌幅就是相对这个价算的。
· 右键「以当前价重置今日基准」可切回“从此刻开始算”；「改用当日开盘价基准」切回开盘价口径。

【配置文件】
优先放在 exe 同目录：GoldDock.ini；若该目录不可写，则退到 %APPDATA%\GoldDock\config.ini。
删除它即恢复默认位置与默认设置。主要键：
  interval=5          刷新间隔（秒）
  spread=0            浙商点差，0 = 自动
  alert=1             跌幅提醒阈值（%），0 = 关闭
  bg.alpha=92         背景不透明度 0~100
  bg.color / fg.color / up.color / down.color   颜色（RRGGBB）
  sge.open.date|price|time   当日开盘价缓存
  base.manual.date    手工重置基准的日期

【网络】
每 N 秒请求一次（默认 5 秒），两个接口都是只读 GET/POST，不需要登录、不需要 key。

【系统要求】
Windows 10 64 位。.NET Framework 4.x（Win10 自带，无需安装）。

【自检命令】
  GoldDock.exe --selftest out.txt    把两个数据源的取数结果写到 out.txt
  GoldDock.exe --snapshot out.png    把卡片渲染成 png（不显示窗口）
